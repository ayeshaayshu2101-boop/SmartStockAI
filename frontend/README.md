\# SmartStock AI – Frontend



\## Overview

The SmartStock AI frontend is a user-friendly web interface for managing inventory. It allows users to view stock information and manage products through an interactive dashboard.



\## Features

\- Login Interface

\- Inventory Dashboard

\- View Inventory Statistics

\- Add Products

\- Edit Product Details

\- Delete Products

\- Search Products

\- View Stock Information



\## Technologies Used

\- React.js

\- JavaScript

\- HTML

\- CSS

\- Vite

\- Lucide React Icons



\## Folder Structure

\- `src/` – React application source code

\- `App.jsx` – Main application component

\- `index.html` – HTML entry point

\- `package.json` – Project dependencies and scripts



\## Prerequisites

\- Node.js

\- npm



\## How to Run



1\. Open a terminal in the project folder.

2\. Navigate to the frontend directory:



&#x20;  ```bash

&#x20;  cd frontend

&#x20;  ```



3\. Install dependencies:



&#x20;  ```bash

&#x20;  npm install

&#x20;  ```



4\. Start the development server:



&#x20;  ```bash

&#x20;  npm run dev

&#x20;  ```



5\. Open the local URL displayed in the terminal.



\## Backend Connection

The frontend communicates with the backend API configured in the application. Ensure the backend server is running before testing inventory operations.
