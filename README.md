# SmartStock AI — React + Spring Boot + MySQL

Beginner-friendly full-stack starter based on the submitted abstract.

## Requirements
- Java 17+
- Node.js 20+ (18+ usually works with current Vite)
- MySQL 8+
- VS Code

## 1. Create the MySQL database
Open MySQL Workbench or a MySQL terminal and run:

```sql
CREATE DATABASE smartstock;
```

The Spring Boot app creates tables automatically.

## 2. Configure database credentials
Open `backend/src/main/resources/application.properties` and set your MySQL username/password:
```properties
spring.datasource.username=root
spring.datasource.password=YOUR_MYSQL_PASSWORD
```
If your MySQL root account has no password, leave the password empty.

## 3. Run the backend
Open a terminal in VS Code:
```bash
cd SmartStockAI/backend
```
Run:
```bash
mvn spring-boot:run
```
Backend URL: `http://localhost:8080`

If `mvn` is not recognized, install Maven or use the Maven wrapper generated by Spring Initializr. (This starter does not include the wrapper.)

## 4. Run the frontend
Open a SECOND terminal:
```bash
cd SmartStockAI/frontend
npm install
npm run dev
```
Open the local URL printed by Vite, usually `http://localhost:5173`.

## Demo login
- Admin: `admin` / `admin123`
- Staff: `staff` / `staff123`

These are demo credentials for a college prototype. Replace them with database-backed users and securely hashed passwords before real use.

## Included features
- JWT login and ADMIN/STAFF roles (demo users are in-memory)
- Product create/read/update/delete
- Stock quantity and expiry-date tracking
- Record a sale; sale quantity is deducted from stock
- Dashboard counts, sales total, low-stock and near-expiry indicators
- Simple stock-replenishment suggestion using recent recorded sales

## Notes
- Set a product's quantity to a number at or below 5 to see the low-stock indicator.
- Set an expiry date within 30 days to see the near-expiry indicator.
- The demand suggestion is a simple rule based on recorded sales, not a trained machine-learning model.
- JWT is sent in the Authorization header by the frontend.
